# Bundled track artwork

The 16 unique panel textures are 500 × 500 crops from page 2 of the supplied
2026 track-construction manual. They preserve the road printing and scale to
one Godot GridMap cell (900 × 900 mm). The hand-authored assembly cell array is
on page 2 of the same manual.

The manual's panel legend (page 1) lists type I once and type J five times.
The assembly drawing (page 2) labels 41 occupied cells with type I twice and
type J four times. The simulator follows the illustrated 41-cell assembly,
not the conflicting inventory tally; it does not hide this source discrepancy.
