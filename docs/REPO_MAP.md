## Key files

- `project.godot`: Godot 4.7 project config (GL Compatibility), main scene `res://scenes/main.tscn`, 1440x900 window.
- `scenes/main.tscn`: Main scene; wires `main.gd`, `simulator_dashboard.gd` and `course_assembly.tscn` with the environment.
- `scripts/main.gd`: Main `Node3D` controller; vehicle/camera constants (tile size, widths, camera and LiDAR placement) and simulation loop.
- `scripts/course_data.gd`: `CourseData` class; tile grid layout of the course (`ROWS_FROM_TOP`) and course constants.
- `python_bridge/jchm.py`: Notebook-safe Jajucha API; authenticated local RPCs to Godot.
- `python_bridge/notebook_host.py`: Loopback notebook host; user code runs only in a child IPython kernel.
- `calibration.json`: Camera intrinsics, vehicle coordinate frame (rear-axle origin, x forward), image size 640x400.
- `export_presets.cfg`: Windows Desktop export preset; excludes caches, build, launcher and CI files.
- `launcher/`: .NET launcher (`JajuchaLauncher.csproj`, `Program.cs`) using Velopack for install/update.
